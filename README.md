# Gemini API Chatbot

A simple **AI chatbot mini project** built using **HTML, CSS, and JavaScript**, integrated with the **Google Gemini API**. Created for learning and experimentation with AI APIs and frontend development.

---

## Features

* Real‑time chat UI
* AI responses using Gemini API
* Dynamic message rendering
* Clean & responsive design

---

## Tech Stack

* HTML, CSS, JavaScript
* Google Gemini API

---

## Project Structure

```
├── index.html
├── style.css
├── script.js
└── README.md
```

---

## How It Works

1. User enters a message
2. JS sends request to Gemini API
3. API returns AI response
4. Response is shown in chat UI

---

## API Setup

Add your Gemini API key in `script.js`:

```js
const API_KEY = "YOUR_API_KEY";
```

 Client‑side API key is not secure for production.
